# XDU Reminder Service (西电校园生活智能提醒后台守护系统)

<p align="center">
  <b>专注于西电校园生活的无感、自动化提醒守护服务</b><br>
  涵盖课前提醒、考试提醒与宿舍低电量报警，兼顾便捷可视化配置与后台常驻守护。
</p>

---

## 🌟 核心特性

- ⏰ **课前 30 分钟强提醒**：对接西电本科生 eHall 教学管理系统，精准计算当日教学周、星期几排课节次，提前推送包含课程名称、教室地点与授课教师的详细提醒。
- 📝 **考试日程提前关注**：自动同步期末与阶段性考试日程，考前一天晚上 20:00 提前预警，考前半小时再次推送考试科目与考场座位号。
- ⚡ **宿舍电费实时监控**：对接西电校园网电控系统，支持 AES 签名鉴权与数据解密，宿舍剩余电量低于阈值（默认 50 度）自动触发低电告警。
- 🔐 **智能人机验证与认证引擎**：
  - **自动滑块识图**：内置图像 NCC 归一化互相关匹配与 Sigmoid 曲线鼠标轨迹模拟算法，秒级自动破解统一认证滑块拼图，全程无感知。
  - **自选二次认证 (MFA)**：支持按需切换手机短信或企业微信动态码，杜绝重复发送；首次完成认证后记录设备指纹，长久受信免重复验证。
  - **Cookie 会话持久化**：采用底层域名/路径级独立 CookieStore，避免多子系统同名 Cookie 冲突，重启免密秒级直接拉取数据。
- 📢 **丰富的多渠道通知支持**：
  - **Windows 报错强提醒 (windows_alert)**：系统级红叉模态置顶弹窗 + 严重错误音，穿透 Session 0 服务隔离，打游戏、看电影或全屏写代码时绝对不漏课！
  - **Windows 桌面通知 (Toast)**
  - **QQ 邮箱 / 各类 SMTP 邮件提醒**
  - **微信推送 (Server酱 / PushPlus)**
  - **QQ 消息推送 (Qmsg酱)**
  - **iOS 推送 (Bark)**
  - **钉钉群机器人 Webhook**
- 🖥️ **双重运行模式**：
  - **Windows 原生服务**：开机自启、崩溃自动重启守护，无控制台黑框打扰。
  - **Docker / 群晖 NAS 容器**：跨平台一键部署，24 小时不间断守护。

## 🚀 快速上手

### 方式一：Windows 本机部署

1. **首次配置**：
   - 运行 `xdu-reminder.exe`，浏览器将自动弹出配置页面（`http://localhost:5800`）；
   - 输入西电学号与统一认证密码，勾选需要的提醒渠道（如 QQ 邮箱、报错弹窗等）；
   - 点击“保存并启动登录服务”。
2. **一键转入后台静默守护**：
   - 在运行状态页面点击**【一键安装后台服务并安全退出配置程序】**；
   - 注册为 `XDUReminder` Windows 服务后，配置程序自动关闭，服务开机自启且无感知常驻。

### 方式二：Docker / 群晖 NAS 部署

已自带 `Dockerfile` 与 `docker-compose.yaml`：
```bash
# 启动容器
docker-compose up -d --build

# 访问 Web 管理配置界面
http://<NAS_IP>:5800
```

## 🛠️ 项目技术栈

- **核心语言**：Python 3.11+
- **网络客户端**：`httpx` (HTTP/2, CookieJar 深度管理)
- **定时调度器**：`APScheduler` (CronTrigger / DateTrigger)
- **图像算法**：`Pillow` + `numpy` (NCC 模板匹配)
- **密码学算法**：`pycryptodome` (AES-CBC / PKCS7)
- **Web 框架**：`Flask` + `Jinja2`
- **后台守护**：Windows NSSM / Docker Compose
